Cấu hình Firebase Realtime Database

Mỗi người chơi cần dùng cùng một databaseURL. Dán URL database (không cần API key nếu rules cho phép đọc/ghi). Có thể lưu 2 project miễn phí.

Cách tạo nhanh (gói miễn phí Spark):
1. Vào console.firebase.google.com → tạo project → Build → Realtime Database → Create Database.
2. Chọn location, chế độ Test mode (hoặc Rules mẫu bên dưới).
3. Copy URL hiện trên đầu database, dạng https://xxx-default-rtdb.firebaseio.com, dán vào Server 1.
4. Làm tương tự với tài khoản Google thứ 2 nếu muốn Server 2.
Rules mẫu cho chơi thử (ai có URL cũng đọc/ghi được): 
{
  "rules": {
    "lobby": { ".read": true, ".write": true },
    "rooms": { ".read": true, ".write": true }
  }
}
Lưu ý: mật khẩu phòng là khóa ở màn hình lobby (hash SHA-256), không phải mã hóa dữ liệu. Với bạn bè chơi thử thì đủ; đừng dùng cho giải đấu có thưởng.
Chế độ thử nghiệm: chọn “Thử nghiệm (cùng trình duyệt)” để mở nhiều tab trên cùng máy, không cần Firebase.
